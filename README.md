# Bot de Arbitragem

Repositório técnico do projeto **Arbitragem Crypto**.

## Estado atual

A estrutura de governança foi inicializada, mas **nenhuma versão funcional do arbitrador está consolidada aqui ainda**. Não trate este repositório como fonte de uma versão operacional até que um commit seja explicitamente marcado como estável no Carlos OS.

## Regras

- `main` representa somente estado aprovado.
- Mudanças relevantes devem ser feitas em branch de trabalho.
- Nunca commitar API keys, secret keys, tokens ou credenciais.
- Versões estáveis devem apontar para commit/tag explícito.
- Bugs relevantes devem ter teste de regressão.
- Alterações materiais devem gerar changelog e checkpoint no Carlos OS.

## Configuração

Credenciais devem ser fornecidas exclusivamente por variáveis de ambiente ou mecanismo seguro equivalente. Use placeholders nos exemplos.

## Fonte de contexto

Decisões, requisitos, bugs, invariantes e checkpoints ficam no **Carlos OS / Notion**. O GitHub é a fonte oficial dos arquivos e versões de código quando consolidados.
